这个文件夹内的内容是给 AI 阅读项目辅助使用的，当然你也可以看来了解项目结构。
首先，项目还处于早期的阶段，有很多类似于 test 字样的变量或者占位的方法、类等。我不会在开发阶段为了追求规范性去改它们，AI 在修改代码和阅读项目时也不要去随便修改以及指出这些，认为是错误。

## 项目概览

一款基于 Arc 框架的 RTS + 自动化多平台游戏。

## 模块结构

| 模块 | 路径 | 说明 |
|------|------|------|
| core | core/ | 主逻辑，全平台共享 |
| desktop | desktop/ | 桌面启动器（SDL3） |
| android | android/ | Android 入口 |
| android-old | android-old/ | sdk14 的老安卓兼容版本，通常不用管，也别提议删,目前此模块处于瘫痪状态 |
| tools | tools/ | 工具 IconGen/TexturePackerTool |
| annotation | annotation/ | 注解以及其处理器 |
| arc | arc/ | Arc fork 的 git submodule |

## 资源

- assets/ —— 字体(normal.ttf)、本地化(language_zh_CN.properties)、着色器、精灵图集
- assets-origin/ —— 原始素材(icon, sprites 子目录)(scheme 不要去管那是我的 AIDE 的配色文件)
- docs/ —— 游戏设定文档,不过目前已废弃

尽可能遵守note中的要求

## 三个要点

- **组件与实体是生成物**:`base.ecs` 由 `annotation` 模块在编译期生成,源码里没有;改动走 `type.def` 下的 `@Component`/`@Entity`。
- **帧序**:`Systems.updateAll` = `e.sync()`(热量/能量/能力)→ 组件系统(按 index)→ `e.update()`。入口 `Vergvoke.update` → `Game.update`,仅 `Game.inGame && !focusPaused` 时跑。
- **销毁只在主线程**:后台线程(BulletProcess/RouteSystem)判死只能 `Entities.markDead` 登记,由 `GameProcess` 统一销毁。
