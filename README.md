# Vergvoke (also know as "十一舰队)

A real-time strategy and automation game built with Arc (yes, it's Anuken's Arc).(really?)

This project will take a long time to develop — really, a very long time. There is still a lot left to build and improve.

## For VS Code

The Java language support from Red Hat does not correctly recognize the project modules, and I am not sure why.

The Java Platform extension for Visual Studio Code seems to work better, but please use version <= 26. Newer versions require JDK 21 or later, while this project currently uses JDK 17.

> Note: If the project modules are not recognized correctly in VS Code, try using the Java Platform extension with a compatible version.
