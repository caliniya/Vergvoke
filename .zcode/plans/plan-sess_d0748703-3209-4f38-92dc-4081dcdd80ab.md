# 导航组件 + 导航系统(独立线程)实施计划

## 架构设计

```
NavigationComp (type.def.comps, @Component index=7, proc="NavigationSystem")
  ├─ 数据:path/pathIndex/pathed/targetX/targetY(从 MoveComp 迁入)+ @Import x/y/speed/speedX/speedY/angle
  └─ @Updata:每单位导航逻辑(算路径→算速度向量→到达判定→stopAndRemove)
       ↓ 编译期生成 Unit.update_NavigationComp(float)
NavigationSystem (type.def.systems, 手写薄调度层, @SystemDef(name="NavigationSystem", thread="nav", index=1))
  └─ update():锁内快照 WorldData.moveunits → 逐单位调 e.update_NavigationComp(delta)
       ↓ 由生成的 Systems.startThreads() 实例化并 init(true) 起 60TPS 独立线程
替代 UnitMath(删除)
```

## 改动清单

### 1. ECProcessor 扩展(annotation/.../ecs/ECProcessor.java)
- **generateComponentSystems**(:1761):建立 proc→thread 映射(从 `types(SystemDef.class)` 取)。thread 为 main 的 proc 照旧生成 `base.ecs.<proc>` 组件系统类;**thread 非 main 的 proc 跳过类生成**(@SystemDef 手写类即驱动者),实体的 `update_<Comp>` 方法生成不受影响。
- **generateSystems**(:1810):新增生成方法 `Systems.startThreads()`——遍历非 main(也跳过 test)线程的 @SystemDef 类,按 index 顺序生成 `new X().init(true)`,实例收进新增的 `public static final Ar<System<?>> threaded`;线程视图字段(main/nav Class[])生成逻辑不变。

### 2. SystemProcessor
- 现有校验已覆盖(非 main proc 必须有同名 @SystemDef;thread 必须有 @ThreadDef 或保留名)。不新增校验;若 NavigationSystem 构造器非 public,生成代码编译期即报错,天然兜底。

### 3. 新组件 NavigationComp(core/src/.../type/def/comps/NavigationComp.java)
- `@Component(name="Navigation", index=7, proc="NavigationSystem")`
- 迁入字段:`pathed`、`path`(Ar\<Point2\>)、`pathIndex`、`@Save(1) targetX`、`@Save(2) targetY`
- `@Import`:`x/y`(基类)、`speed/speedX/speedY/angle`(MoveComp)
- `@Updata` 体:UnitMath 的 calculatePath + calculateVelocityVector + stopAndRemove 逻辑改为每单位方法(常量 NODE_REACH_TOLERANCE 内联为字面量;行为保持一致,findPath 硬编码 unitSize=2/capability=1 暂保留)

### 4. MoveComp 瘦身
- 删除 `pathed/path/pathIndex/targetX/targetY`,改为 `@Import` 借用(targetX/targetY/path/pathIndex/pathed 来自 NavigationComp——@Updata 体引用不变,实体里只有一份字段)
- `@Save` 重排:x(1)、y(2);保留 speed/speedX/speedY/angle/arriveRange/moving/velocityDirty

### 5. UnitDef 更新
- comps 增加 NavigationComp:`StateComp + MoveComp + NavigationComp + WeaponComp + TargetComp`

### 6. 手写 NavigationSystem(core/src/.../type/def/systems/NavigationSystem.java,新包)
- `@ThreadDef(name="nav")` + `@SystemDef(name="NavigationSystem", thread="nav", index=1)`(index=1,nav 线程内唯一)
- `extends System<NavigationSystem>`,`update(delta)`:synchronized 快照 moveunits → 遍历调 `e.update_NavigationComp(delta)`(逻辑在组件体里,系统只做调度);构造器里赋 `public static NavigationSystem it`

### 7. 删除 UnitMath + Data 接线
- 删 `system/world/UnitMath.java`
- `Data.loadSystems()`(:57):移除 `UnitMath.it = new UnitMath()`
- `Data.enter()`(:86):移除 `UnitMath.it.init()`,在 BulletProcess init 之后调 `Systems.startThreads()`(nav 系统随世界就绪后启动;ThreadedStop 停机复用 System 基类既有机制)

### 8. 存档版本 bump
- @Save 字段归属/顺序变化(targetX/targetY 从 Move 挪到 Navigation,写入顺序改变),SAVE_VERSION 2→3(io 层,定位后改)

### 9. 文档同步(ai-using/main.txt)
- 组件 index 清单(1-7)、实体组合、系统清单(UnitMath→NavigationSystem@nav)、Systems.updateAll 帧序描述
