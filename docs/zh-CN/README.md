# AKA 十一舰队

这是一个基于 Arc 引擎开发的即时战略与自动化游戏（是的，使用的是 Anuken 的 Arc）。

这个项目会需要很长时间来开发——真的会很长很长。它仍然还有很多内容需要完成和完善。

## 项目简介

这是一款以 RTS（实时战略）与自动化系统为核心的游戏，目标是融合资源管理、单位控制、生产链与策略决策等元素。

从目前阶段来看，这个项目还处于早期开发状态，内容还在持续扩展中。

## VS Code 相关说明

在 VS Code 中，Red Hat 提供的 Java 语言支持似乎无法正确识别该项目的模块结构，我也不太清楚具体原因。

目前看起来，Visual Studio Code 的 Java Platform 扩展可以更稳定地工作，但请使用版本 <= 26。

较新的版本要求 JDK >= 21，而这个项目目前使用的是 JDK 17。

> 注意：如果你在 VS Code 中遇到项目模块无法被正确识别的问题，可以优先尝试使用兼容版本的 Java Platform 扩展。

## 说明

这个项目的开发计划会比较长期，仍然需要持续迭代与改进。后续可能会加入更多内容、机制和系统设计。

如果你正在参与开发，建议在本地开发环境中保持 JDK 17 的版本一致，避免出现兼容性问题。
